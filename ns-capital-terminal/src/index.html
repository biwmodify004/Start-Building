ใช้กับ client ที่รองรับ MCP HTTP และ Bearer token; local ใช้ URL นี้ได้ ส่วน remote ต้องเปิดผ่าน HTTPS ของคุณ

ติดตั้งครั้งแรก
  1. เปิด MT4 หรือ MT5 ของโบรกและล็อกอินบัญชี
  2. ดาวน์โหลดชุดติดตั้ง เริ่ม bridge.py บน Windows / VPS แล้วนำ token มาใส่ด้านบน
  3. สำหรับ MT4 ให้ติด EA ส่งราคาและตั้ง UTC offset; สำหรับ MT5 ใช้แพ็กเกจ Python ของ MetaQuotes
  4. เพิ่ม mcp_server.py ใน MCP client เพื่อให้ AI อ่านราคาและแท่งเทียนจาก gateway เดียวกัน
ดาวน์โหลด Broker + MCP Bridgeคู่มือติดตั้งละเอียด ↗

ใช้ HTTPS สำหรับ gateway บน VPS หรือ localhost บนเครื่องเดียวกัน หาก browser บล็อกการเข้าถึงเครือข่ายในเครื่อง ให้ใช้ HTTPS endpoint หรือเปิดเว็บแบบ local ตามคู่มือ

มี MCP ทั้ง local stdio และ HTTP สำหรับ client ที่รองรับ Token การเชื่อม remote MCP ของ ChatGPT ยังต้องตั้ง HTTPS และระบบยืนยันตัวตนที่รองรับเพิ่ม

Sample เป็นข้อมูลสังเคราะห์ เลือก Binance สำหรับ Crypto, ตลาดโลกสำหรับกราฟ TradingView หรือเชื่อม Broker Bridge เพื่อใช้ราคาและแท่งจาก MT4/MT5 ของคุณใน Vela

Research ใช้ตัวอ่านคีย์เวิร์ด ไม่ใช่ Quant AI ของ LuxAlgo รองรับ EMA crossover, Bollinger re-entry และ prior-range breakout เท่านั้น มีตัวอย่างเซิร์ฟเวอร์เชื่อม AI ในซอร์สโค้ด

Backtest เข้าแท่งถัดไปหลังสัญญาณ ใช้ ATR ของแท่งสัญญาณ คิดค่าใช้จ่ายสองด้าน และเลือก Stop ก่อนเมื่อแท่งเดียวแตะทั้ง SL/TP ค่า Drawdown วัดจาก Equity ณ ปิดแท่ง ข้อมูลบนกราฟหลายช่องอาจต่างกัน ให้ตรวจชื่อสินทรัพย์ในผลลัพธ์

ข้อมูลผู้ใช้บันทึกเฉพาะในเบราว์เซอร์นี้ ใช้ Backup เพื่อย้ายเครื่อง ไม่มีการส่งคำสั่งเงินจริง ไม่มีการรับประกันผลตอบแทน
