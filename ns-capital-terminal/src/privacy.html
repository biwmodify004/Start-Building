การใช้ข้อมูลใน NS Capital

แพลตฟอร์มนี้เป็นพื้นที่ทำงานของเจ้าของ Broker Bridge หน้าเว็บ GitHub Pages เปิดดูได้ทั่วไป ข้อมูลบัญชีโบรกเกอร์อยู่ที่ Backend ของเจ้าของ ไม่ถูกอัปโหลดเข้า Repository โดยระบบ

Google Login

ใช้ Google Identity Services เพื่อยืนยันตัวตน Backend ตรวจ ID token และรายชื่อผู้มีสิทธิ์ ใช้ Google subject ID เป็นตัวระบุ พร้อมชื่อและอีเมลสำหรับแสดงสถานะ ไม่ขออ่าน Gmail, Drive หรือรหัสผ่าน Google

ID token ไม่ถูกเก็บถาวร เซสชันอยู่ในหน่วยความจำของ Browser/Bridge และหมดอายุสูงสุด 30 นาที เซิร์ฟเวอร์เก็บเฉพาะ Hash ของเซสชันและผูกกับ Origin/บัญชี Terminal กดออกจากระบบเพื่อเพิกถอนเซสชันของแท็บนี้ได้ ไม่มี Client Secret ในเว็บ

ข้อมูลพอร์ตและ Journal

Bridge เก็บประวัติเทรด ต้นทุน โน้ต Risk และ Receipt ใน SQLite บนเครื่อง/VPS ของเจ้าของ โปรไฟล์และงานวิจัยบางส่วนอยู่ในเบราว์เซอร์ จัดการ Backup/ลบข้อมูลกับเจ้าของ Bridge โดยไม่เผยแพร่ฐานจริงหรือ Token ใน Issue สาธารณะ

AI และรายงานที่แชร์

AI Coaching ส่งสถิติไปยังโมเดลที่เจ้าของตั้งค่า ไม่ส่งเลขบัญชี Token หรือข้อความโน้ตส่วนตัว รายงาน Track Record สร้างเมื่อยินยอม มีสถิติรวมและ Token รายงานแยก กำหนดวันหมดอายุและยกเลิกได้

บริการภายนอก

GitHub Pages, Google Identity, Binance, วิดเจ็ต TradingView และผู้ให้บริการโมเดลที่เลือกประมวลผลข้อมูลการเชื่อมต่อตามบริการของตน อ่านรายละเอียดจาก Google และ GitHub ได้

ติดต่อผู้ดูแลผ่านช่องทางที่คุณใช้ขอสิทธิ์เข้า Bridge เมื่อนำแพลตฟอร์มนี้ไปให้สมาชิกอื่นใช้งาน ผู้ดูแลต้องปรับข้อมูลผู้ให้บริการ ช่องทางติดต่อ และการเก็บรักษาให้ตรงการใช้งานจริงก่อนเปิดบริการ
